# Install Laravel Breeze (Blade + Dark Mode)

Laravel Breeze provides a simple, minimal authentication scaffolding (login, register, password reset, email verification, and profile management) using Tailwind CSS and Alpine.js.

## Commands Run

Run from inside the `laravel-web-api/apps/` folder:

```bash
composer require laravel/breeze --dev
php artisan breeze:install blade --dark
php artisan migrate
npm install
npm run build
```

### `app/Http/Controllers/ProfileController.php`

```php
 1  <?php
 2
 3  namespace App\Http\Controllers;
 4
 5  use App\Http\Requests\ProfileUpdateRequest;
 6  use Illuminate\Http\RedirectResponse;
 7  use Illuminate\Http\Request;
 8  use Illuminate\Support\Facades\Auth;
 9  use Illuminate\Support\Facades\Redirect;
10  use Illuminate\View\View;
11
12  class ProfileController extends Controller
13  {
14      public function edit(Request $request): View
15      {
16          return view('profile.edit', [
17              'user' => $request->user(),
18          ]);
19      }
20
21      public function update(ProfileUpdateRequest $request): RedirectResponse
22      {
23          $request->user()->fill($request->validated());
24
25          if ($request->user()->isDirty('email')) {
26              $request->user()->email_verified_at = null;
27          }
28
29          $request->user()->save();
30
31          return Redirect::route('profile.edit')->with('status', 'profile-updated');
32      }
33
34      public function destroy(Request $request): RedirectResponse
35      {
36          $request->validateWithBag('userDeletion', [
37              'password' => ['required', 'current_password'],
38          ]);
39
40          $user = $request->user();
41
42          Auth::logout();
43
44          $user->delete();
45
46          $request->session()->invalidate();
47          $request->session()->regenerateToken();
48
49          return Redirect::to('/');
50      }
51  }
```
