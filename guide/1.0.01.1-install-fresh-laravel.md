# Installation Fresh Laravel

## Step 1: Create a New Laravel Project

```bash
composer create-project laravel/laravel laravel-web-api
```

## Step 2: Navigate into the Project Folder

```bash
cd laravel-web-api
```

## Step 3: Configure Database

Edit `.env` and update the database credentials:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel-web-api
DB_USERNAME=root
DB_PASSWORD=
```

## Step 4: Run Database Migrations

```bash
php artisan migrate
```

## Step 5: Start the Development Server

```bash
php artisan serve
php artisan serve --host=192.168.0.151 --port=8000
```
Or visit locally-
```
http://192.168.0.151/multi-app-ecosystem-2/laravel-web-api/public/
```
