# Fix Broken UI + Make Project Folder-Flexible (Subfolder Deployment)

The UI rendered with broken styles/scripts when the app was served through Apache at `http://192.168.0.151/multi-app-ecosystem-2/laravel-web-api/`, even though `php artisan serve` worked fine.

## Root Cause

Laravel lives inside `laravel-web-api/apps/` while Apache serves the app from `laravel-web-api/`. Two problems:

1. **Assets 404.** The front controller generates correct asset URLs (`.../laravel-web-api/build/assets/...`), but the real Vite build files are stored in `apps/public/build/`. `php artisan serve` works because its document root **is** `apps/public`; Apache has no such mapping, so every asset request fell through to `index.php` and returned HTML instead of CSS/JS.

2. **Security hole found while debugging.** The old deny rule `RewriteCond %{REQUEST_URI} ^/apps/` only matched apps installed at the web root. In a subfolder the request URI is `/multi-app-ecosystem-2/laravel-web-api/apps/...`, so `apps/.env`, `apps/config/*`, etc. were served directly over HTTP (200).

## Fix

- Rewrote `.htaccess` to (a) deny direct access to `apps/` internals using a **relative** pattern so it works from any folder, and (b) serve static assets from `apps/public`.
- Rewrote `laravel-web-api/index.php` to add a web-server-agnostic fallback that serves any file that exists under `apps/public` (with MIME types) before bootstrapping Laravel.

### `laravel-web-api/.htaccess`

```apache
<IfModule mod_rewrite.c>
    <IfModule mod_negotiation.c>
        Options -MultiViews -Indexes
    </IfModule>

    RewriteEngine On

    # Deny direct web access to the Laravel application internals. Everything inside
    # the "apps" directory is protected except "apps/public", which is the only
    # directory that may be served. These are relative patterns, so the project can
    # be moved to any folder without breaking.
    RewriteRule ^apps/(?!public/) - [R=403,L]

    # Handle Authorization Header
    RewriteCond %{HTTP:Authorization} .
    RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]

    # Handle X-XSRF-Token Header
    RewriteCond %{HTTP:x-xsrf-token} .
    RewriteRule .* - [E=HTTP_X_XSRF_TOKEN:%{HTTP:X-XSRF-Token}]

    # Redirect Trailing Slashes If Not A Folder...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_URI} (.+)/$
    RewriteRule ^ %1 [L,R=301]

    # Serve static assets from the Laravel public directory (apps/public) when the
    # file does not already exist at the web root. The PHP front controller also
    # serves these as a fallback, so this just makes common asset requests faster.
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^((build|assets|css|js|images|img|media|storage|fonts|files|uploads)/.+|favicon\.ico|robots\.txt)$ apps/public/$1 [L]

    # Send Requests To Front Controller...
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>
```

### `laravel-web-api/index.php`

```php
<?php

use Illuminate\Foundation\Application;
use Illuminate\Http\Request;

define('LARAVEL_START', microtime(true));

// Determine if the application is in maintenance mode...
if (file_exists($maintenance = __DIR__.'/apps/storage/framework/maintenance.php')) {
    require $maintenance;
}

// Serve static files from the Laravel public directory (apps/public). This makes
// the application work from any folder and any web server that routes the request
// here, without needing rewrite rules for every asset type.
$requestUri = $_SERVER['REQUEST_URI'] ?? '/';
if (($queryPosition = strpos($requestUri, '?')) !== false) {
    $requestUri = substr($requestUri, 0, $queryPosition);
}
$uri = parse_url($requestUri, PHP_URL_PATH);
if ($uri === null || $uri === '') {
    $uri = '/';
}

$scriptName = str_replace('\\', '/', $_SERVER['SCRIPT_NAME'] ?? '');
$basePath = rtrim(dirname($scriptName), '/');
if ($basePath !== '' && str_starts_with($uri, $basePath)) {
    $uri = substr($uri, strlen($basePath));
}
$uri = rawurldecode($uri);

$publicDir = realpath(__DIR__.'/apps/public');
if ($publicDir !== false && $uri !== '' && $uri !== '/') {
    $requested = realpath($publicDir.$uri);
    if ($requested !== false
        && str_starts_with($requested, $publicDir.DIRECTORY_SEPARATOR)
        && is_file($requested)) {
        $mimeTypes = [
            'css' => 'text/css',
            'js' => 'text/javascript',
            'mjs' => 'text/javascript',
            'json' => 'application/json',
            'html' => 'text/html',
            'htm' => 'text/html',
            'txt' => 'text/plain',
            'xml' => 'application/xml',
            'map' => 'application/json',
            'webmanifest' => 'application/manifest+json',
            'png' => 'image/png',
            'jpg' => 'image/jpeg',
            'jpeg' => 'image/jpeg',
            'gif' => 'image/gif',
            'svg' => 'image/svg+xml',
            'webp' => 'image/webp',
            'avif' => 'image/avif',
            'ico' => 'image/x-icon',
            'bmp' => 'image/bmp',
            'woff' => 'font/woff',
            'woff2' => 'font/woff2',
            'ttf' => 'font/ttf',
            'otf' => 'font/otf',
            'eot' => 'application/vnd.ms-fontobject',
            'wasm' => 'application/wasm',
            'pdf' => 'application/pdf',
            'mp4' => 'video/mp4',
            'webm' => 'video/webm',
            'mp3' => 'audio/mpeg',
            'wav' => 'audio/wav',
        ];
        $extension = strtolower(pathinfo($requested, PATHINFO_EXTENSION));
        header('Content-Type: '.($mimeTypes[$extension] ?? 'application/octet-stream'));
        header('Content-Length: '.filesize($requested));
        readfile($requested);
        exit;
    }
}

// Register the Composer autoloader...
require __DIR__.'/apps/vendor/autoload.php';

// Bootstrap Laravel and handle the request...
/** @var Application $app */
$app = require_once __DIR__.'/apps/bootstrap/app.php';

$app->handleRequest(Request::capture());
```

Lines added: `13-76` (asset fallback servlet). The original bootstrap block (`78-85`) is unchanged.

How it works:
- Lines `16-23` take the raw request URI, strip the query string, and parse the path.
- Lines `25-30` strip the script base path (`/multi-app-ecosystem-2/laravel-web-api`) so only the app-relative path remains — this is what makes the file **folder-flexible** (move the project anywhere and it still resolves).
- Lines `32-37` resolve the requested path against `apps/public` and reject anything that escapes it (`realpath` + `str_starts_with` prefix check) — no path-traversal risk, no serving of `.env`, etc.
- Lines `38-74` serve the file with the correct MIME type, `Content-Length`, and `exit`.

## Notes

- `.htaccess` patterns are **relative** to the `laravel-web-api/` directory, so the project keeps working if moved to any other folder or host.
- The `index.php` fallback handles any future asset type (images, fonts, uploads, etc.) even if not listed in the `.htaccess` fast path.
- Git currently flags `LF will be replaced by CRLF` on Windows for both edited files; this is cosmetic.
